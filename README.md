🏥 Healthcare Intelligence Dashboard – Power BI

A Power BI dashboard designed to transform hospital data into a centralized, decision-ready analytics system. This project brings hospital operations, patient insights, and record-level data together to support data-driven healthcare management.


📌 Project Overview

Healthcare data is often scattered across systems, making it difficult for hospital administrators to obtain a clear and holistic view of performance.
This dashboard consolidates key data points into a 3-page interactive Power BI report, enabling leaders to monitor operations, patient flow, and care quality with clarity.


📊 Dashboard Pages

Page	Focus Area

Hospital Summary	High-level KPIs, occupancy, ER time, treatment cost, and feedback
Patient Summary	Patient demographics, LOS, admissions, ICU, deaths, and departmental stats
Details View	Patient-level drill-down for audit, billing, and case review


🧠 Key Features

📍 360° view of hospital performance

🔍 Drill-through navigation for patient-level analysis

🚦 KPI monitoring for ER time, LOS, ICU cases, feedback & more

🗂 Segmentation by age, gender, department & state

📈 Clean UI for intuitive data storytelling and exploration


🛠 Tech Stack

Tool	Usage

Power BI	Dashboard & Data Visualization
Power Query	Data cleaning & preparation
DAX	Measures & data modeling


📁 Dataset

Total Records: 2,500+

Data Type: Patient, operational, clinical & feedback data

Data was cleaned, structured, and modeled before visualization


🚀 How to Use

1. Clone or download this repository

2. Open the .pbix Power BI file in Power BI Desktop

3. Interact with slicers, filters, and drill-throughs to explore insights
